# Инструкция по запуску алгоритма высокочастотной торговли

## Настройка окружения

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Установите необходимые зависимости:
```bash
pip install -r requirements.txt
```

Если файл requirements.txt отсутствует, установите зависимости вручную:
```bash
pip install numpy pandas gymnasium ccxt.async_support stable-baselines3 ta python-dotenv optuna torch
```

## Настройка API ключей

1. Создайте файл `.env` в корневой директории проекта
2. Добавьте в него ваши API ключи от Bybit:
```
API_KEY=ваш_api_ключ
API_SECRET=ваш_api_secret
```

## Поддерживаемые торговые пары

Алгоритм поддерживает одновременную торговлю на 10 ликвидных парах:
1. DOGE/USDT:USDT
2. BTC/USDT:USDT
3. ETH/USDT:USDT
4. BNB/USDT:USDT
5. SOL/USDT:USDT
6. XRP/USDT:USDT
7. ADA/USDT:USDT
8. AVAX/USDT:USDT
9. DOT/USDT:USDT
10. MATIC/USDT:USDT

## Быстрый старт и тестирование

Алгоритм использует новый подход к обучению:
- Сбор данных в реальном времени (1 тик = 1 секунда)
- Автоматическое начало обучения после накопления 100 тиков
- Не требуется предварительная загрузка исторических данных
- Возможность тестирования работоспособности без длительного ожидания

## Запуск алгоритма

### Вариант 1: Использование скрипта запуска
```bash
python run_trading.py
```

### Вариант 2: Прямой запуск основного файла
```bash
python Main.py
```

## Параметры алгоритма

Алгоритм настроен со следующими параметрами:
- **Риск**: 1% от текущего баланса на позицию
- **Интервал торговли**: 1 секунда
- **Глубина стакана**: 50 уровней
- **Количество сделок в ленте**: 100 последних сделок
- **Торговые пары**: 10 ликвидных пар (см. список выше)
- **Тики для обучения**: 100 тиков для начала обучения

## Мониторинг работы

Алгоритм выводит информацию в консоль:
- Текущий баланс
- Полученные данные стакана и ленты сделок для каждой пары
- Принятые торговые решения для каждой пары
- Выполненные ордера
- Возникающие ошибки
- Прогресс сбора данных (тики)

## Остановка алгоритма

Для остановки алгоритма нажмите `Ctrl+C` в терминале где он запущен.

## Важные замечания

1. **Риск**: Алгоритм использует 1% от баланса для каждой позиции, что минимизирует риски
2. **Частота**: Высокая частота торговли (1 секунда) может привести к большому количеству ордеров
3. **Комиссии**: Учитывайте комиссии биржи при оценке прибыльности
4. **Тестирование**: Рекомендуется сначала протестировать на бумаге или с минимальным балансом
5. **Многопарная торговля**: Алгоритм одновременно торгует на 10 парах, распределяя риск
6. **Быстрый старт**: Обучение начинается автоматически после сбора 100 тиков (примерно 1-2 минуты)

## Устранение неполадок

### Ошибка API
- Проверьте правильность API ключей в файле `.env`
- Убедитесь, что API ключи имеют необходимые разрешения

### Ошибка подключения
- Проверьте подключение к интернету
- Убедитесь, что биржа Bybit доступна

### Ошибка данных
- Алгоритм автоматически пропускает ошибки получения данных и продолжает работу
- Подробная информация об ошибках записывается в лог
