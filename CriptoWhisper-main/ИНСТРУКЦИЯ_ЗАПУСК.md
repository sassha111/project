## ⚠️ ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### 1. Ошибка: "Cannot connect to host api.bybit.com"
**Причина:** Нет доступа к интернету или блокировка DNS

**Решение:**
```bash
# Проверьте интернет
ping api.bybit.com

# Проверьте DNS
nslookup api.bybit.com

# Попробуйте другой DNS (Google DNS)
# Linux: sudo nano /etc/resolv.conf
# Добавьте: nameserver 8.8.8.8

# Windows: Настройки сети → Изменить DNS на 8.8.8.8
```

### 2. Ошибка: "ModuleNotFoundError: No module named 'ta'"
**Решение:**
```bash
pip install ta-lib
# Или для Ubuntu:
sudo apt install python3-ta-lib
```

### 3. Ошибка: "Invalid API credentials"
**Решение:**
Проверьте .env файл:
```bash
cat .env
# Должно быть:
API_KEY=pWOLonr9bGxepUfxRa
API_SECRET=4GkvsmHaGxZquYYBSBEHKlfSdnRCu49Y25Iw
```

### 4. Скрипт зависает на обучении
