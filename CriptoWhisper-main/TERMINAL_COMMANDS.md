# Команды для запуска алгоритма в терминале

## Основные команды запуска

### 1. Запуск основного алгоритма (рекомендуемый)
```bash
python run_trading.py
```

### 2. Прямой запуск основного файла
```bash
python Main.py
```

## Необходимые зависимости

Перед запуском убедитесь, что установлены все зависимости:

```bash
pip install -r requirements.txt
```

Или установите вручную:
```bash
pip install numpy pandas gymnasium ccxt.async_support stable-baselines3 ta python-dotenv optuna torch
```

## Настройка API-ключей

Для работы алгоритма с реальными данными (в демо-режиме используется симуляция), создайте файл `.env` в корне проекта:

```
API_KEY=ваш_api_ключ
API_SECRET=ваш_api_secret
```

## Режимы работы

Алгоритм поддерживает несколько режимов работы:

1. **Демо-режим** (по умолчанию): Используется симуляция торговли
2. **Обучение**: Алгоритм обучается на основе полученных данных
3. **Торговля**: Реальная торговля на бирже Bybit (требуется настройка API-ключей)

## Поддерживаемые торговые пары

Алгоритм одновременно торгует на 10 ликвидных парах:
- DOGE/USDT:USDT
- BTC/USDT:USDT
- ETH/USDT:USDT
- BNB/USDT:USDT
- SOL/USDT:USDT
- XRP/USDT:USDT
- ADA/USDT:USDT
- AVAX/USDT:USDT
- DOT/USDT:USDT
- MATIC/USDT:USDT

## Параметры алгоритма

- **Риск**: 1% от текущего баланса на позицию
- **Интервал торговли**: 1 секунда
- **Глубина стакана**: 50 уровней
- **Количество сделок в ленте**: 100 последних сделок

## Мониторинг работы

Алгоритм выводит информацию в консоль:
- Текущий баланс
- Полученные данные стакана и ленты сделок для каждой пары
- Принятые торговые решения для каждой пары
- Выполненные ордера
- Возникающие ошибки
- Прогресс сбора данных (тики)

## Остановка алгоритма

Для остановки алгоритма нажмите `Ctrl+C` в терминале, где он запущен.

## Примечания

- Алгоритм использует 1% от баланса для каждой позиции, что минимизирует риски
- Высокая частота торговли (1 секунда) может привести к большому количеству ордеров
- Комиссии биржи учитываются при расчетах
- Рекомендуется сначала протестировать на бумаге или с минимальным балансом
- Алгоритм одновременно торгует на 10 парах, распределяя риск
- Обучение начинается автоматически после сбора 100 тиков (примерно 1-2 минуты)
